CFIST Anonymous Review Code
This repository contains the anonymous reproducibility materials for CFIST, a session-level purchase-conversion prediction framework. The package provides the source implementation, experiment configurations, data-preparation utilities, evaluation scripts, verification tools, tests, structured empirical records, and manuscript-oriented figure and table assets.
Repository contents
.
├── configs/          Experiment and model configuration files
├── figures_source/   Editable source definitions for the workflow and architecture figures
├── manifests/        Dataset-source metadata, provenance notes, and record checksums
├── outputs/          Generated figures, tables, and integrity metadata
├── records/          Structured logs, cohort summaries, fold summaries, and evaluation records
├── scripts/          Data preparation, training, evaluation, analysis, and rendering entry points
├── src/cfist/        CFIST implementation and supporting utilities
├── tests/            Unit tests for core data and model components
└── tools/            Package-audit and reference-record construction utilities
Configuration files
The configs/ directory contains YAML files used to define the data paths, cohort construction, model architecture, optimization settings, temporal validation protocol, model-selection procedure, evaluation metrics, random seeds, and ablation controls.
- default.yaml defines the full experiment configuration.
- smoke.yaml defines a reduced configuration for pipeline checks.
- baselines.yaml defines the supported comparison models and their settings.
Source package
The src/cfist/ directory contains the main Python implementation:
- model.py implements the CFIST network, including relational event tokenization, funnel-biased local sequence encoding, partial-order graph encoding, representation fusion, and prediction heads.
- dataset.py provides iterable session datasets and batch collation.
- schema.py defines event normalization and input schemas.
- cohort.py constructs observed-prefix prediction examples and cohort records.
- sessionization.py provides visitor-event sessionization utilities.
- folds.py implements chronological block assignment, rolling outer folds, development splits, and overlap checks.
- preprocessing.py implements fold-specific preprocessing and feature transformation.
- training.py contains model fitting and prediction routines.
- losses.py implements the training objectives and GroupDRO-related components.
- calibration.py provides post-hoc calibration utilities.
- posthoc.py stores and applies frozen post-hoc processing states.
- metrics.py implements discrimination, calibration, and selective-prediction metrics.
- uncertainty.py contains uncertainty-related computations.
- statistics.py provides bootstrap comparison and multiple-testing utilities.
- robustness.py implements event-deletion, timestamp-noise, and stage-noise perturbations.
- perturbations.py contains reusable perturbation operations.
- baselines.py and baseline_training.py define comparison models and their training routines.
- selection.py provides candidate configurations for chronological model selection.
- prediction_io.py handles prediction-file input and output.
- storage.py provides sharded session storage and iteration utilities.
- sampling.py contains deterministic sampling helpers.
- config.py loads configurations, manages seeds, and writes configuration metadata.
- constants.py defines shared feature and graph constants.
Data and cohort scripts
The scripts/ directory includes the following data-oriented entry points:
- download_data.py retrieves the declared public datasets using the source manifest.
- prepare_otto.py prepares the OTTO development and internal-validation data.
- prepare_retailrocket.py prepares the Retailrocket external-validation data and supports alternative inactivity thresholds.
- clean_outputs.py removes generated run outputs from the working output directories.
Dataset identifiers, source URLs, licenses, expected schemas, and event-stage mappings are recorded in manifests/data_sources.yaml. Record provenance is described in manifests/record_provenance.md.
Training and evaluation scripts
- run_selection.py performs nested chronological configuration selection within each outer historical interval.
- train_cv.py trains and evaluates CFIST across rolling temporal validation folds.
- train_final.py trains the final development-data model used by the external-validation workflow.
- run_baselines.py runs the configured comparison models.
- import_official_predictions.py imports prediction files generated by supported official baseline implementations.
- external_validate.py performs frozen external validation on the prepared external dataset.
- run_ablations.py executes component and objective ablations.
- run_robustness.py evaluates configured input perturbations.
- run_low_data.py performs deterministic training-fraction analysis.
- run_prevalence_sensitivity.py performs evaluation-only prevalence sensitivity analysis without model refitting.
- run_statistics.py performs paired comparisons, bootstrap analyses, and multiplicity adjustment.
- run_full_pipeline.py coordinates the complete configured workflow.
- run_smoke.py performs a reduced end-to-end pipeline check.
Verification and reporting scripts
- verify_records.py checks the structure and consistency of the packaged records and writes an integrity report.
- verify_empirical_outputs.py compares newly generated outputs with the packaged manuscript-aligned record layer using configurable tolerances.
- generate_figures.py creates the manuscript-oriented figures from the structured records.
- generate_tables.py creates manuscript-oriented CSV and Markdown tables from the structured records.
- tools/audit_package.py audits the repository structure and packaged materials.
- tools/build_reference_records.py constructs the organized reference-record layer used by the verification and reporting utilities.
Structured records
The records/ directory organizes the packaged experiment materials by purpose:
- cohort/ contains cohort-flow records.
- folds/ contains temporal-fold summaries.
- logs/ contains fold-level and external-validation logs.
- results/ contains structured files for cross-validation, baseline comparisons, external validation, ablations, calibration, robustness, interpretability, efficiency, low-data analysis, prevalence sensitivity, and study comparisons.
- statistics/ contains statistical-test records.
Generated assets
The outputs/figures/ directory contains generated PNG and PDF figures. The outputs/tables/ directory contains generated CSV and Markdown tables together with a table index. The figures_source/ directory contains Mermaid source files for the workflow and model-architecture diagrams.
Tests
The tests/ directory contains unit tests covering cohort construction, temporal folds, model execution, and record validation. Shared test fixtures are defined in tests/conftest.py.
Integrity metadata
The manifests/record_manifest.json file lists the packaged record files and their metadata. The generated outputs/integrity_report.json file records the verification status and checksums used to confirm the consistency of the included record layer.
